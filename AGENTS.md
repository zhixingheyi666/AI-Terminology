# Vocabulary entry guidelines

- When the user provides a word and an English sentence, record the word, its definitions, the original sentence, a Chinese translation, and a short word-level note.
- Do not add grammar breakdowns, example-analysis sections, example tags, or sentence-level context analysis unless the user explicitly asks for sentence analysis or grammar analysis in that request.
- Keep personal example `note`, `exampleTags`, `contextAnalysis`, and `grammarAnalysis` empty for ordinary vocabulary additions.
- The user may still explicitly request a detailed example analysis; only then populate those fields.
